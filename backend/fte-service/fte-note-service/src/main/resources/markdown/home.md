# 笔记服务API文档

## 简介

笔记服务提供了用户笔记的管理功能，包括笔记的创建、更新、删除和查询等操作。

## 认证说明

所有API都需要通过Bearer Token认证，除了标记为内部接口的API。

### 获取Token

1. 通过认证服务获取Token：
   ```
   POST http://localhost:10020/oauth/token
   ```

2. 在请求头中添加Token：
   ```
   Authorization: Bearer {your_token}
   ```

## 主要功能

1. **笔记管理**
   - 创建笔记
   - 更新笔记
   - 删除笔记
   - 查询笔记

2. **按课程查询**
   - 获取指定课程的笔记列表

3. **分页查询**
   - 支持分页获取笔记列表

## 使用说明

1. 所有请求都需要使用JSON格式
2. 用户ID可以从Token中获取，也可以在请求体中提供
3. 内部接口只能通过服务间调用使用

## 错误码说明

| 错误码 | 描述 |
| ------ | ---- |
| 00000  | 成功 |
| A0400  | 用户请求参数错误 |
| A0401  | 用户未登录 |
| B0001  | 系统执行出错 |
